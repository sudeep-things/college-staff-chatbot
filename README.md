# 🎓 College Staff Chatbot

A simple interactive college staff chatbot built using Python and Streamlit.

The project converts a basic terminal-based staff information program into a browser-based chat application.

## ✨ Features

- 💬 Interactive chat interface
- 🎓 College staff information
- 👥 Staff list in sidebar
- 🔎 Staff name detection
- 🗑️ Clear chat option
- 🐍 Python-based chatbot logic
- 🌐 Streamlit web interface
- 🚀 GitHub-ready project
